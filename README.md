# Web Engineering

A semester-long repository containing my **Web Engineering** laboratory assignments, classwork, practical exercises, source code, documentation, and web development projects.

This repository is maintained throughout the semester to keep all Web Engineering coursework organized, accessible, and properly documented in a single GitHub repository.

---

## Repository Purpose

The purpose of this repository is to:

- Organize all Web Engineering laboratory work in one place.
- Maintain a single repository for the entire semester.
- Keep laboratory tasks, classwork, and practical exercises structured and easy to navigate.
- Store source code and project files for each laboratory.
- Document practical exercises and concepts covered throughout the course.
- Track the development of web-based projects throughout the semester.
- Maintain a clean and consistent Git and GitHub workflow.
- Build a collection of practical web development projects as part of the course.
